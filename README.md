# Recovery Agent

A React + TypeScript + Vite application implementing a 7-step banking recovery case workflow.

## Setup

1. Install Node.js 20+ from https://nodejs.org/
2. Open the workspace in VS Code.
3. Run:
   ```bash
   npm install
   npm run build
   ```

## Available scripts

- `npm run dev` — Start the Vite development server
- `npm run build` — Build the app for production
- `npm run preview` — Preview the production build

## Features

- Landing page with recovery value proposition
- AI-style incident intake chat interface
- Issue-specific transaction selection
- Evidence upload simulation and skip warning
- AI diagnosis with structured recovery likelihood
- Customized dispute packet generation
- Case tracker with staged escalation and resolution
